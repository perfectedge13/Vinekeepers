## Implementation constraints

1. **SpaceOperations interface:** Change return type from `Object` to typed results: `CreateRoomResult createRoom(CreateRoomRequest)`, `CreateThreadResult createThread(CreateThreadRequest)`.
2. **CreateRoomResult / CreateThreadResult:** Success case holds id (String); failure case holds failure reason enum. Optional: message/code for diagnostics.
3. **Failure reason enums:** In connectors package (e.g. CreateRoomFailureReason: NO_REQUEST, NO_GATEWAY, BAD_GUILD, CREATE_RETURNED_NULL, PERMISSION_DENIED, UNKNOWN; CreateThreadFailureReason: NO_REQUEST, NO_GATEWAY, BLANK_CHANNEL, CREATE_RETURNED_NULL, UNKNOWN). DiscordSpaceOperations maps internal failures to these.
4. **DiscordSpaceOperations:** Return CreateRoomResult/CreateThreadResult (success with id, or failure with reason). Keep sentinel string values in a single place: e.g. CreateRoomResult.sentinel() / CreateThreadResult.sentinel() or constants that equal current "CHANNEL_CREATE_FAILED" and "THREAD_CREATE_FAILED" so actions can translate result → string for run() return.
5. **CreateChannelAction / CreateThreadAction:** Call SpaceOperations; **translate** typed result to String: on success use result.getId(), on failure use CHANNEL_CREATE_FAILED/THREAD_CREATE_FAILED (same string as today). So run(Event, state, bind) continues to return Object (String) for storeIn and branch compatibility. Preserve Discord and lifecycle behavior; no change to PostChannelMessageAction, LifecycleContextStore, CursorCloudRunMonitor, CreateLifecycleContextAction except if they reference sentinel constant (keep constant on CreateChannelAction/CreateThreadAction).
6. **SpaceOperationsRegistryTest:** Stub SpaceOperations must return CreateRoomResult/CreateThreadResult (e.g. success with id or failure with reason).
7. **OutboundGateway:** No change; createTextChannel/createThreadChannel still return String (id or null). DiscordSpaceOperations maps null to failure result with reason.
8. **Spec updates:** Add new assets (CreateRoomResult, CreateThreadResult, failure enums) to connectors-registry; update asset role for SpaceOperations and DiscordSpaceOperations (return typed results). No new requirement keys; no schema key changes.
