# Contracts

# APIs

`EventSource.start(EventBus)` — connector registers with the bus and begins emitting events.

# Schemas

Event payload includes Discord message fields such as `content`, `channelId`, `authorId`, and optional `mentions`. Reply delivery uses `channelId`, `messageId`, and `content`.

# Interfaces

- **`ConnectorRegistry`:** `register(connectorId, adapter)`, `get(connectorId)` to store and retrieve connector adapters by id (e.g. `discord`).
- **`ConnectorAdapter`:** `registerBots(List<BotDefinition>, ConnectorContext)`; adapter performs per-bot gateway/sender/default registration only; Bootstrap retains sink and action registration.
- **`ConnectorContext`:** Generic context for adapters: EventBus, OutboundDeliveryRouter, and optional **FeatureRoomStateStore** / **LifecycleContextStore** for Discord owned-space ingress filtering; Discord-specific options in DiscordConnectorConfig.
- **`DiscordConnectorConfig`:** Discord-specific config (e.g. defaultTokenEnvKey from root defaultDiscordTokenEnvKey) passed to DiscordConnectorAdapter constructor.
- **`DiscordConnectorAdapter`:** Implements ConnectorAdapter; constructor takes DiscordConnectorConfig and routedBotIds; registerBots does per-bot gateway/sender/default registration only.
- **`EventSource`:** `start(EventBus)` and lifecycle methods for publishing connector events.
- **`ReplySender`:** Generic sender contract (`send(channelId, messageId, content)`). Core uses this interface; **DiscordReplySender** extends it.
- **`OutboundGateway`:** Connector execution surface with Discord-shaped API (guildId, createTextChannel, createThreadChannel, addPermissionOverride). Used only by connector-owned code (e.g. DiscordSpaceOperations, DiscordAppReplySink) and OutboundDeliveryRouter; not a generic core abstraction. **DiscordGateway** extends it for receive/send and interaction operations.
- **`DiscordReplySender`:** Extends `ReplySender`; `send(channelId, messageId, content)` for routing workflow replies back to Discord. Implemented by `OutboundDeliveryRouter` for actual sender resolution.
- **`ReplyTargetResolver`:** Interface: `resolve(Event)` → `Optional<ReplyTarget>`. Connector-owned; engine looks up by connector id. Bootstrap registers the Discord implementation via `engine.registerReplyTargetResolver("discord", new DiscordReplyTargetResolver())`.
- **`DiscordReplyTargetResolver`:** Implements `ReplyTargetResolver`. Reads Discord payload (channelId, messageId, interactionId, token, deferred) and returns **InteractionTarget** or **ChannelTarget**.
- **`OutboundDeliveryRouter`:** (1) Routes outbound delivery (ReplySender) by target and lifecycle/feature-room context; implements ReplySender and delegates to resolved sender; no silent fallback when configured bot has no sender. Supports **sendAs** / **sendAsRole** (legacy fallback paths) and **sendAsExplicit** / **sendAsRoleExplicit** for workflow explicit sender (errors when unresolved). (2) Holds and resolves gateways by bot/channel for connector-owned code; gateway = connector execution surface for channel/thread/permission and send. `getGatewayForChannel(channelId)` returns the gateway for that channel when the lifecycle bot has one, or **null** when the lifecycle bot has no gateway (no default). `getSelfUserIdForBot(botId)` returns that bot's Discord user id from its gateway `getSelfUserId()`, or null. Used by DiscordSpaceOperations and DiscordAppReplySink.
- **`SpaceOperations`:** Interface: `createRoom(CreateRoomRequest)` → **CreateRoomResult**, `createThread(CreateThreadRequest)` → **CreateThreadResult** (typed success with id or failure with **CreateRoomFailureReason** / **CreateThreadFailureReason**). Resolved by source prefix via **SpaceOperationsRegistry**; workflow actions use **WorkflowCapabilitySupport.sourcePrefix(event)** — null/blank or unregistered prefix yields fail-closed (no Discord default). **CreateChannelAction** and **CreateThreadAction** translate results to channel/thread id or sentinel (`CHANNEL_CREATE_FAILED`/`THREAD_CREATE_FAILED`) for `run()` so storeIn and branch use id/sentinel. **DiscordSpaceOperations** implements for Discord and uses only request getters (no raw map access); createTextChannel, createThreadChannel, setDeliveryTargetId, addPermissionOverride.
- **`CreateRoomRequest`:** Record with explicit intent fields: `sourceId`, `guildId`, `channelName`, `lifecycleOwnerBotId`, optional **`participantBotIds`** (List&lt;String&gt;), `project`, `codeChange`. Static **`from(Event event, Map<String, Object> state, Map<String, Object> bind)`** performs bind-then-state resolution (bind overrides state for guildId, channelName, lifecycleOwnerBotId, participantBotIds; project and codeChange from state only). When **participantBotIds** is non-empty, **DiscordSpaceOperations.createRoom** applies **addPermissionOverride** for each bot (resolve userId via **OutboundDeliveryRouter.getSelfUserIdForBot(botId)**); else fallback to single **lifecycleOwnerBotId**. Consumed by **SpaceOperations.createRoom**.
- **`CreateThreadRequest`:** Record with explicit intent fields: `sourceId`, `channelId`, `threadName`, `contextId`. Static **`from(Event event, Map<String, Object> state, Map<String, Object> bind)`** performs bind-then-state resolution (bind overrides state for channelId, threadName, contextId). Caller/factory owns bind/state resolution; consumed by **SpaceOperations.createThread**.
- **`DiscordMessageIngressMode` / `DiscordInteractionIngressMode` / `DiscordIngressModes`:** Config-driven policy for which Discord events each bot publishes to the engine (`none`, `routed`, `owned_spaces` for messages; `none`, `routed`, `own_messages`, `owned_spaces` for interactions). Defaults combine YAML **routing** and **handlesOwnedSpaces**; optional **identities.discord.ingress** in bot YAML overrides.
- **`DiscordOwnedSpacePredicate`:** Returns whether a channel/thread id is an owned feature room (participant) or legacy lifecycle channel for the bot, using **FeatureRoomStateStore** and **LifecycleContextStore**.
- **`DiscordGateway`:** Extends `OutboundGateway`. In addition to receive/send and interaction lifecycle, provides `createTextChannel(guildId, channelName)` (returns channel id or null on failure), `getSelfUserId()` (returns the bot's Discord user id), and `addPermissionOverride(channelId, guildId, targetUserId, allow, deny)` for lifecycle room permission overwrites. The workflow action `create_channel` builds **CreateRoomRequest** and delegates to **SpaceOperations** (DiscordSpaceOperations). **JdaDiscordGateway** registers message and/or interaction listeners per **DiscordIngressModes**; fully outbound-only when both modes are `none`. **DiscordAppReplySink** casts to `DiscordGateway` when calling interaction-specific methods (e.g. defer, update).
