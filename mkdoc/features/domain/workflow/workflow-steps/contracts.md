# Contracts

# APIs

None. Workflow steps are internal runtime components loaded from YAML configuration.

# Schemas

`WorkflowDefinition` stores an id plus ordered step configs. `StepResult` carries message, stored values, next-step data, `StepOutcome`, and optional `OutboundResponse` (richReply). Step config may include `intent` (e.g. present_choices, confirm_action), `choices`, `confirmLabel`, `cancelLabel`, or `fields`; when present, the step may produce an `OutboundResponse` with a `ResponseIntent` for the connector to render.

# Interfaces

- **`WorkflowStep`:** executes one configured step against the current event and state. For **capture_field**, optional **transforms** (list: trim, lower, upper, default); **trimAndLower: true** maps to [trim, lower] and **overrides** transforms when both are present. **extract_event** step: fromEvent list of { from, storeIn, default?, transforms? }; from = payload.\<key\> or context.\<field\>; list-valued context stored as List. For **branch**, when may include operator and transform (state value only; trim, lower, upper); operators: equals, not_equals, blank, nonblank, contains, starts_with, regex (full-string), one_of.
- **`WorkflowAction`:** named action contract invokable from the DSL.
- **`WorkflowActionRegistry`:** resolves workflow actions by name for `call_action` steps. For `call_action`, **bind has precedence over state** for action inputs (explicit step bind overrides state for the same keys). **create_channel** and **create_thread** build **CreateRoomRequest** and **CreateThreadRequest** via static **from(Event, state, bind)** (bind-then-state resolution in DTO); actions resolve **SpaceOperations** via **WorkflowCapabilitySupport.sourcePrefix(event)** (prefix from event; null/blank or unregistered prefix → fail-closed: action returns `CHANNEL_CREATE_FAILED` or `THREAD_CREATE_FAILED` — no Discord default). **SpaceOperations** (connectors): `createRoom(CreateRoomRequest)` → **CreateRoomResult**, `createThread(CreateThreadRequest)` → **CreateThreadResult** (typed success/failure); **CreateChannelAction** and **CreateThreadAction** translate results to id or sentinel for state. **CreateRoomRequest** record: sourceId, guildId, channelName, lifecycleOwnerBotId, optional **participantBotIds**, project, codeChange. **CreateThreadRequest** record: sourceId, channelId, threadName, contextId. **DiscordSpaceOperations** uses only request getters; createRoom applies permission overwrites for each **participantBotIds** entry (or lifecycleOwnerBotId). Registered lifecycle room actions: `create_channel`, `create_thread`, `post_channel_message` (interpolates `content` from merged state + bind, bind overrides; optional **asRole**/ **asBotId** for sendAs/sendAsRole), `provision_bot_instance`, `create_lifecycle_context`, **provision_room_participants** (storeIn: featureRoomParticipants), **initialize_feature_room_state**, `launch_cursor_run` (authoritative for Luna; uses `CursorInstructionComposer` for prompt; returns acknowledgement with optional status e.g. "Status: launching"). Workflows can branch on `channelId == CHANNEL_CREATE_FAILED` after `create_channel`.
- **Planning OpenAI (connectors + workflow):** **`OpenAiCallContext`** — event, workflow state map, **`activitySummary`** (non-blank triggers user-visible progress). **`OpenAiPlanningProgressSink`** — callback invoked before each planning HTTP completion when context is present; default NOOP, production **`OpenAiPlanningProgressPoster`** implements via **`PostChannelMessageAction`** (**`**Update:**`** prefix) when **`OPENAI_PLANNING_DISCORD_PROGRESS`** is not false. **`OpenAiChatClient`** — optional sink; INFO duration logging; optional truncated redacted payload logs per **`OPENAI_LOG_PLANNING_BODIES`** / **`OPENAI_LOG_BODY_MAX_CHARS`**; **`embedTexts`** for batched `/embeddings` calls used by planning RAG. Planning actions **`run_request_expansion_llm`**, **`run_llm_planning_synthesis`**, and **`StructuredLlmArtifactUpsertPass`** construct **`OpenAiCallContext`** for their **`complete(...)`** calls.
- **Planning RAG (workflow):** **`prep_planning_repo_grounding`** — **`PrepPlanningRepoGroundingAction`** after a materialized checkout exists; **`PlanningRepoGroundingService`** orchestrates **`PlanningRagConfig`**, **`QdrantPlanningClient`**, **`RepoGroundingParquetStore`**, **`RepoFileChunker`**, **`GitRepoBranchResolver`**, and **`GroundingChunkRecord`** rows. **`spread_plan_workspace_signals`** merges selected **`planningRag*`** fields into **`planningRepoEvidenceJson`**. **`run_llm_planning_synthesis`** may add **`planningRagRetrievalText`** to prompt context when **`planningRagAvailable`**. Degrades without failing when RAG is off or misconfigured.
- **Plan readiness and approval (workflow):** **`PlanReadinessCalculator`** — computes **`PlanConfidence`** (readiness **NOT_READY** / **CONDITIONALLY_READY** / **READY** / **BLOCKED**, **confidenceScore**, **confidenceReasons**, **structuredKnownFactCount** / **materialUnknownCount** / **materialUnknownLabels**) from gaps, substantive unresolved questions, blocking issues and findings, rubric mean, packet-posted inference, and related signals; exposes **`APPROVAL_CONFIDENCE_THRESHOLD`** (**0.85**) as the single launch-approval bar. **`PlanningApprovalGateSupport.validateApproveAllowed`** applies that threshold to persisted **confidenceScore** when present, together with packet posted, critique lifecycle complete, **READY** readiness, and canonical intake/clarification posture.
- **Canonical coordinator clarification (canonical_v1):** **`SilentPlanningSynthesisService`**, **`PlanningWorkspacePreflightService`**, **`CanonicalPlanningGapEngine`**, **`PlanningConfidenceService`**, **`CanonicalGapResolutionPolicy`**, **`PlanningQuestionComposer`**, **`CanonicalClarificationSpreadBuilder`**, **`ClarificationProjection`**, **`PlanningMaterialCyclePacing`**, **`PlanningMaterialRoutingOutcome`**, **`PlanningCanonicalDecisionSupport`** — production path described in REQ-WORKFLOW-002; **`PlanningGapAskCounts`** / **`PlanningConfidenceBreakdown`** serialize to optional plan JSON fields for pacing and audit.
