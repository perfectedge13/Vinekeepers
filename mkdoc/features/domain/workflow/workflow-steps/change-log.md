SpaceOperations API is request-based: `createRoom(CreateRoomRequest)`, `createThread(CreateThreadRequest)`. See WorkflowCapabilitySupport.java, CreateRoomRequest.java, CreateThreadRequest.java; workflow-registry ASSET-WORKFLOW-CAPABILITY-SUPPORT; connectors-registry ASSET-CREATE-ROOM-REQUEST, ASSET-CREATE-THREAD-REQUEST.

Bootstrap registers the Discord SpaceOperations capability. See ASSET-SPACE-OPERATIONS, ASSET-SPACE-OPERATIONS-REGISTRY, ASSET-DISCORD-SPACE-OPERATIONS; CreateChannelActionTest, CreateThreadActionTest, DiscordSpaceOperationsTest, SpaceOperationsRegistryTest.
- **Workflow DSL (workflow-dsl-routing-policy-lite):** **WorkflowTransforms** utility provides shared string transforms (trim, lower, upper, default; null/blank-safe). **WorkflowConditionEvaluator** evaluates branch conditions with operators equals, not_equals, blank, nonblank, contains, starts_with, regex (full-string), one_of; optional transform list applied to state value before compare. **ExtractEventFieldsStep** (`extract_event`) populates state from event via `fromEvent` list (from = payload.key or context.field, storeIn, default, transforms; list-valued context stored as List). **BranchStep** uses WorkflowConditionEvaluator; branch supports optional transform list on state value (trim, lower, upper only). **CaptureFieldFromEventStep** supports both trimAndLower and transforms list; when both present, **trimAndLower wins** (backward compatibility).
