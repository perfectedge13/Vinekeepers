# Rules

## Overview

Rules are Cursor rule files (`.mdc`) that define alwaysApply or optional behavior: spec-driven workflow, schema/drift gates, validation, and project defaults.

| Rule | Description | Link |
|------|-------------|------|
| vinekeepers-standards | Vinekeepers coding standards, app flow, and config-based bots. | [vinekeepers-standards](vinekeepers-standards.md) |
| spec-workflow | Spec-driven change workflow (specs.yml is source of truth). Core workflow + project defaults. | [spec-workflow](spec-workflow.md) |
| spec-workflow-core | Core spec-driven workflow — gates, removal/rename, output. Project-agnostic. | [spec-workflow-core](spec-workflow-core.md) |
| guardrails | Pre-implementation checklist for spec-driven changes. | [guardrails](guardrails.md) |
| spec-workflow-vinekeepers | This project's defaults are in .cursor/project.yml and specs/specs.yml. Optional; delete when porting. | [spec-workflow-vinekeepers](spec-workflow-vinekeepers.md) |
