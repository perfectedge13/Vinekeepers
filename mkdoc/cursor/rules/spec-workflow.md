# Spec-workflow

## Summary

Spec-driven change workflow with specs.yml as source of truth. Delegates to core workflow and project defaults.

## Key points

- Follow the **core** spec workflow for all coding tasks (Schema Gate, Spec Drift Gate, steps 1–9, removal/rename, output format).
- Reference **spec-workflow-core.mdc** for full rules.
- Validation and project defaults are defined in the core rule.
